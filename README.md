# ProofDeck Blog

The official engineering, credentialing, and fraud prevention blog for [ProofDeck](https://www.proofdeck.app).

Built with **Next.js 14 (App Router)**, **Tailwind CSS**, and **Lenis** smooth scrolling.

## Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
npm start
```
